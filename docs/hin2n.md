# hin2n 组网模块使用说明

> hin2n（[switch-iot/hin2n](https://github.com/switch-iot/hin2n) 内化，内核 n2n v1/v2/v2s/v3）已作为 **TVBox 内置模块**随 APK 一起安装，**不再需要单独下载/安装 hin2n APK**。
> 全部界面均为电视遥控器（D-pad）设计，颜色随 TVBox 当前主题变化。

---

## 1. 入口

有两个入口，打开的是同一个 TV 引导页：

1. **首页 →「历史」所在入口行的「组网」卡片**（推荐，整行会随下方列表一起上下滚动）；
2. **首页顶栏的 hin2n 图标**。

是否显示入口由内置配置 `hin2nEntry` 控制（默认显示）。

**入口图标状态颜色**（两处入口同步变色）：

| 颜色 | 状态 | 含义 |
| --- | --- | --- |
| 主题默认色（白） | 未拨号 / 已断开 | 尚未发起连接，或连接已正常停止 |
| 黄 | 拨号中 | 已发起连接、正在与超节点握手注册 |
| 绿 | 已连接 | 组网成功，可正常互访 |
| 红 | 失败 / 异常断开 | 拨号失败、或与超节点异常断开 |

> 模块没有独立桌面图标，只能从 TVBox 内进入；连接 VPN 后可按 Home 键回桌面，组网保持。

## 2. TV 引导页

横屏页面，遥控器上下左右移动焦点、OK 键点击：

| 控件 | 作用 |
|------|------|
| 状态 | 未连接 / 连接中… / 已连接 / 与 supernode 断开（自动重连）/ 连接失败 |
| 当前配置 | 显示当前选中的组网配置名 |
| 日志区 | 实时滚动 edge 运行日志（可在编辑页调日志级别） |
| **连接 / 断开** | 首次连接系统会弹「连接请求」VPN 授权框，选确定并勾选不再询问 |
| **配置管理** | 进入配置列表：切换选中项 / 编辑 / 删除 |
| **新建配置** | 直接进入空白配置编辑页 |
| **Ping** | 输入对端虚拟 IP 做连通性测试，结果弹窗显示 |
| **开机启动：开/关** | hin2n 自己的开机开关（见 §5） |
| **清空日志** | 清空页面日志显示 |
| 返回 | 回首页（不断开 VPN） |

## 3. 新建 / 编辑配置

在配置管理页选中某条配置按 OK 即进入编辑页；字段与原版 hin2n 完全一致（共 28 项），保存后立即生效。

### 3.1 基本字段

| 字段 | 必填 | 说明 |
|------|------|------|
| n2n 版本 | 是 | v1 / v2 / v2s / v3，默认 **v3**；必须与对端一致 |
| 配置名称 | 是 | 任意名字，如「家里」 |
| IP 获取方式 | 是 | 手动填写 IP / 由超节点自动分配 |
| 虚拟 IP | 手动模式必填 | 如 `10.0.0.6`，同一网络内不能重复 |
| 子网掩码 | 是 | 一般 `255.255.255.0` |
| 组网名称（community） | 是 | 网络组名，最长 20 字符，两端必须一致 |
| 密钥 | 否 | community 密码 |
| 设备描述 | 否 | v2/v3 的设备名 |
| 超节点 | 否 | `地址:端口`；**留空按版本取官方默认**：v1 `hin2n.nton.eu.org:10082`、v2 `…:10086`、v2s `…:10088`、v3 `supernode.ntop.org:7777` |

### 3.2 高级字段（展开「更多设置」）

| 字段 | 默认 | 说明 |
|------|------|------|
| 备用超节点 | 空 | 主超节点不可用时使用 |
| 虚拟 MAC | 空（随机） | 格式 `AA:BB:CC:DD:EE:FF`，留空随机生成 |
| MTU | 1328 | 46–1500 |
| 本地 IP | auto | 本地物理网卡 IP，`auto`/留空自动（v2s/v3） |
| 打洞间隔 | 20 | 秒（v2s） |
| 预先解析超节点 IP | 关 | 启动时先解析域名（v1/v2s） |
| 本地端口 | 0（随机） | edge 监听端口 |
| 允许路由转发 | 关 | 对应 `-r` |
| 接受组播/广播 | 关 | 对应 `-E`；**ARP 依赖它，ping 不通对端时优先尝试打开** |
| 优先 HTTP 隧道 | 关 | 对应 `-H` |
| 日志级别 | 普通 | 错误 / 警告 / 普通 / 信息 / 调试（0–4） |
| 虚拟网关 | 空 | v2/v3，**非空时所有流量都走 VPN**（全局模式） |
| DNS 服务器 | 空 | v2/v3，VPN 内 DNS |
| 加密方式 | Twofish | Twofish / AES-CBC / ChaCha20 / Speck-CTR（v2/v3） |
| 包头加密 | 关 | v2/v3 |
| 设为当前配置 | 是 | 选中后引导页「连接」即使用该条 |

## 4. 静态路由

在 **配置编辑页** 的「静态路由」行填写，让指定网段走 VPN 隧道而不影响其他流量：

```
192.168.8.0/24 10.0.0.13
192.168.9.0/24 10.0.0.13
```

- 格式：`目标网段 网关IP`，每行一条（也可全部写在一行用空格分隔）；网关可省略；
- 带 `/` 的 token 是网段，其后不带 `/` 的 token 是该网段的网关；
- 保存在应用私有 SP（`Hin2n/hin2n_static_routes`），连接时由 VpnService `addRoute` 注入；
- 出厂值可在内置 JSON 的 `hin2n.staticRoutes` 中配置（多条用空格分隔）。

## 5. 两个「开机启动」开关（相互独立）

| 开关 | 位置 | 作用 |
|------|------|------|
| hin2n 开机启动 | 组网引导页「开机启动：开/关」 | 开机后**自动连接 n2n VPN**（需此前已授予 VPN 权限） |
| TVBox 开机启动 | 设置 → 设置其他 →「内置配置」卡片 | 开机后**拉起 TVBox 首页**，不自动连 VPN |

两者互不影响，可任意组合。由同一个 `BootReceiver` 在收到 `BOOT_COMPLETED` 后分别处理。
Android 10+ 部分 TV 固件限制后台拉起页面/前台服务，属系统行为限制。

## 6. 出厂配置在哪改

出厂配置（含默认组网条目的全部 28 个字段、静态路由、开机开关、入口显隐）写死在源码：

[app/src/main/assets/tvbox-config.json](file:///f:/tvbox-n2n/app/src/main/assets/tvbox-config.json) 的 `hin2n` 段。

- 该文件支持 `//`、`/* */` 注释与尾逗号（JSONC）；
- **仅在应用首次启动（组网数据库为空）时播种一次**，之后以用户在界面中的增删改为准；
- 已去除「远程地址配置」，需要不同的出厂/定制配置时，直接改此文件后重新编译 APK。

字段逐项 demo 见 [tvbox-config.example.jsonc](file:///f:/tvbox-n2n/docs/tvbox-config.example.jsonc)。

## 7. 常见问题

1. **点连接立刻回到「未连接」**：未授予 VPN 权限，重新点连接并在系统弹窗确认。
2. **状态已连接但 ping 不通对端**：两端 community/密码/版本是否一致；试试打开「接受组播/广播」（`-E`）；确认虚拟 IP 在同一网段且不冲突。
3. **能 ping 通虚拟 IP 但访问不了对端局域网**：配置静态路由（§4），或让对端开启 IP 转发。
4. **想全局翻墙/走对端网络**：高级设置里填「虚拟网关」（gatewayIp），并按需填 DNS。
5. **日志看细节**：日志级别调「信息/调试」，引导页日志区实时显示，也可在「清空日志」旁复制排查。
