# TVBox-n2n 使用说明

> 面向最终用户（电视盒子 / 智能电视）的操作手册。组网功能（n2n）的详细说明另见 [hin2n.md](file:///f:/tvbox-n2n/docs/hin2n.md)。

---

## 1. 这是什么

TVBox-n2n 是一款电视端影视聚合应用，内置：

- **点播**：多个影视源，分类浏览、选集、搜索、收藏、播放历史；
- **直播**：自定义直播源（txt / m3u / json），支持频道列表、节目单（EPG）、P2P 直播（`tkp2p://`）；
- **组网**：内置 hin2n（n2n）模块，开机可自动连入异地局域网，访问内网 NAS、IPTV、摄像头等；
- 全部基础配置由安装包**内置**，无需再填写任何远程配置地址。

## 2. 安装与选包

### 2.1 该下载哪个 APK？

文件名形如 `TVBox_release-<CPU架构>-<品牌>-<模式>.apk`：

| 维度 | 选什么 |
|------|--------|
| CPU 架构 | 近十年（约 2017 年后）的盒子/电视选 **arm64**；老盒子选 **armeabi**（32 位 v7a）。不确定就先装 arm64，装不上/打不开再换 armeabi |
| 品牌 | 普通设备选 **generic**（包名 `com.github.tvbox.osc.tk`）；海信深度定制机型选 **hisense**（包名不同，可与 generic 版共存） |
| 模式 | Android 5.0 及以上选 **normal**（文件名里显示为 java）；需要 Python 影视源选 **python**；**Android 4.4 设备必须选 legacy**（minSdk19 兼容版） |

> 同系列升级请保持同一包名（generic / hisense 不能互相当作升级包覆盖安装）。

### 2.2 安装

1. 把 APK 拷到 U 盘插入盒子，用「文件管理」打开安装；或通过盒子自带的应用安装功能安装。
2. 首次安装如系统提示「**禁止安装未知来源应用**」，在弹窗中选「去设置」，允许 TVBox 安装应用后返回，安装会自动继续（较新系统上也可能需要手动再点一次安装）。
3. 安装后在应用列表找到 TVBox 打开即可。

### 2.3 应用内下载安装其他 App（或升级 TVBox）

配置中预置的第三方应用、新版 TVBox 安装包都支持应用内直接下载：

- 确认安装后，屏幕**顶部出现下载进度条**（百分比 + 文件名），下载期间可正常使用其他功能；
- 下载完成自动弹出系统安装界面；Android 8 及以上首次会跳「安装未知应用」授权页，允许一次后返回即可自动继续安装；
- 若中途退出了页面也没关系，回到首页会自动继续之前未完成的安装。

## 3. 接口配置（点播源 / 直播源 / 节目单）

进入「**设置**」（首页齿轮图标）→「**接口设置**」区域：

- **点播接口地址**：影视源 JSON 地址（http 链接或本地路径）；
- **直播接口地址**：直播源，支持 txt、m3u、json 三种格式的 URL；
- **节目单地址（EPG）**：直播节目单；
- **代理**：需要走代理时填写。

填写后选「确定」，应用会提示**重启生效**，退出重新打开即可。

> 本版本可能已由安装包**预置默认接口**：预置值只在你从未手动配置过该项时生效；一旦你手动填写过，以后升级安装也不会覆盖你的配置（四项互不影响）。

## 4. 首页导览

```
┌──────────────────────────────────────────────┐
│ 顶栏：日期/WiFi/搜索/单双排/主题/收藏/组网…   │  ← 图标可能被预置方案整体替换
├──────────────────────────────────────────────┤
│  历史 点播 直播 搜索 收藏 推送 文件 设置 组网 │  ← 快捷入口行（随页面一起滚动）
│  ── 影视推荐内容（随当前点播源变化） ──        │
└──────────────────────────────────────────────┘
```

- **历史**：播放记录（点播/直播），可继续观看或清除；
- **点播 / 直播 / 搜索**：进入对应功能；
- **收藏**：收藏的影视；**推送**：手机/电脑推送的点播链接；
- **文件**：本地文件浏览；**设置**：应用设置；
- **组网**：进入 hin2n 组网界面（详见 [hin2n.md](file:///f:/tvbox-n2n/docs/hin2n.md)）；
- 入口行下方是推荐内容，按遥控器**上下键**滚动，焦点到哪内容滚到哪；
- **入口行支持左右拖动**：当入口过多超出屏幕时，按遥控器**左右键**会自动横向滚动，不再被截断；
- 预置方案可能把顶栏或入口行替换成**自定义图标与顺序**（例如直达某个影院、某个系统设置、某个 App），操作方式与普通图标一致；图标指向的 App 未安装时，若预置了下载地址会自动下载安装。

### 4.1 公告条

屏幕顶部或底部可能出现一条滚动公告（由预置方案配置），用于发布通知：

- 可限定每天的显示时段、过期日期，可分别设置在首页/直播/点播是否显示；
- 纯展示信息，不影响任何操作。

## 5. 点播

1. 首页选「**点播**」（或首页直接浏览推荐内容）；
2. 左上角（或菜单中）可**切换影视源**——不同源的内容与解析能力不同，打不开时换一个源试试；
   - 切换时会弹出「**切换源：xxx**」提示并**强制刷新**分类与影片列表（绕过缓存）；
   - 左上角文字的显示规则：预置方案未配置点播接口时，显示内置配置 `home.sourceName` 的默认文字（未配置则显示应用名）；你手动配置过点播接口后，左上角改为显示**当前源名称**；
3. 进入影片：选剧集 → 选择**播放线路** → 开始播放；
4. 播放页遥控器操作：
   - **左右键**：拖动进度（部分源不支持）；
   - **上下键**：切换选集 / 调整音量（按界面焦点）；
   - **OK 键**：显示/隐藏控制栏与选集列表；
   - **MENU 键**：播放设置（解码器、播放器、倍数等）；
   - **返回键**：先退出全屏控制，再按一次返回列表。
5. 收藏、播放历史自动记录；在「收藏」「历史」中管理。

> 部分入口打开的是**专用点播界面**（预置方案配置的独立影院）：它使用单独的影视源，不影响你自己配置的首页源，退出后一切恢复原样。切源操作同样有提示并强制刷新；预置方案还可为它指定**独立主题**（`theme` 字段），影院界面及其播放页的配色/背景与主界面互不影响。

## 6. 直播

进入「**直播**」后默认播放上一次的频道。遥控器操作：

| 按键 | 作用 |
|------|------|
| **OK / 确认（短按）** | 调出**原生频道列表**：上下选台、左右切换频道分组 |
| **长按 OK（网页型源）** | 在「**网页自带界面**（页面内节目单/按钮）」与「全屏视频」之间切换；需要点网页里的按钮时用此模式，用方向键移动焦点、OK 点击 |
| **MENU 键** | 调出**原生直播设置**：线路切换、解码方式、画面比例、节目源、换台反转等 |
| **上 / 下键** | 上一个 / 下一个频道（可在设置里开启「换台反转」） |
| **右键** | 切换下一个**直播源**（同一频道配置了多条线路时） |
| **数字键 0–9** | 直接输入频道号，2 秒内连续输入，输完自动跳转 |
| **返回键** | 退出直播 |

常见情况：

- **黑屏 / 有声音无画面 / 卡顿**：按 MENU → 换「解码方式」（系统解码器 / 软硬解轮流试）；或右键切换线路；
- **网页型直播源**：长按 OK 进入网页界面操作页面里的按钮；平时保持全屏视频模式；
- **P2P 直播（频道地址以 `tkp2p://` 开头）**：走内置 P2P 播放页，人越多越流畅，首次启动需数秒建立邻居连接；
- 节目单（EPG）正常时，频道信息栏会显示当前/后续节目。

## 7. 搜索

- 首页「**搜索**」：对当前影视源搜索；
- 「**快搜**」（部分入口/设置中提供）：同时搜索多个影视源并聚合结果；
- TV 端用屏幕键盘输入首字母或全拼，方向键选词，OK 确认。

## 8. 主题与外观

- 顶栏「**主题**」图标（或设置中）可切换 14 种内置主题（红/蓝/橙/绿/紫……），选择后立即生效并记住；
- 主题切换**只刷新界面，不重新加载点播源数据**，无需等待；
- 预置方案还可增加自定义主题（含多背景图随机切换），配置全局**背景图片**，以及输入框、按钮、入口图标的颜色；
- 预置方案可通过 `themes` 数组**覆盖内置主题**（带 `style` 序号）或**追加全新主题**（不带 `style`），也可为自定义点播入口（`type=vod`）指定 `theme` 独立主题；
- 这些外观每次启动按内置配置应用，不需要手动操作。

## 9. 组网（hin2n）

首页「**组网**」卡片或顶栏组网图标进入。可用功能：连接/断开、查看状态与日志、新建/编辑多组网配置（28 项参数）、Ping 测试、开机自动连接、静态路由。

- 状态颜色：**黄色=连接中，绿色=已连接，红色=失败，原色=未连接**（首页组网图标会同步变色）；
- 首次连接需在系统弹窗中**授予 VPN 权限**；
- **连接失败时原因会写入组网日志页**（如「启动失败：…」），状态变红却看不到日志时先看日志内容再排查；
- 两端的「协议版本 / 组网名称（community）/ 密钥 / 超节点」必须一致，虚拟 IP 不能冲突；
- 注册成功但 ping 不通对端时，在配置高级选项中打开「**接受组播/广播（acceptMulticast）**」再试；
- 详细参数与排查见 [hin2n.md](file:///f:/tvbox-n2n/docs/hin2n.md)。

## 10. 开机自启（两个独立开关）

| 开关 | 位置 | 作用 |
|------|------|------|
| TVBox 开机启动 | 设置 → 内置配置 → 开机启动 | 盒子开机后自动打开 TVBox 首页 |
| 组网开机启动 | 组网页面内的开关 | 开机后自动连接 n2n（前提：之前已授权过 VPN） |

两者互不影响，可分别开关，也可同时打开实现「开机即进 TVBox 且自动组网」。

## 11. 软件升级

- 预置方案可配置升级检查：启动进入首页后如发现新版本，会弹窗显示版本号与更新内容；
- 选「立即升级」后在应用内下载并安装（见 §2.3）；选「以后」则本次启动不再打扰；
- **强制升级**时弹窗没有取消按钮且无法用返回键关闭，必须升级后才能继续使用。

## 12. 常见问题

**Q：装哪个包？**
A：见 §2.1。Android 4.4 一定选 legacy；新设备 arm64 + generic + normal 适用绝大多数情况。

**Q：点播打开没反应/解析失败？**
A：先换一个影视源；同一影片可切换播放线路；MENU 里更换解码器；检查网络是否正常。

**Q：直播黑屏？**
A：MENU 切换解码方式；右键切换直播源线路；网页源尝试长按 OK 切换网页界面。

**Q：换了直播/点播接口地址不生效？**
A：接口设置确定后需要**完全退出并重新打开**应用。

**Q：设置页里的默认值和我预想的不一样？**
A：所有设置项的**出厂默认值**由安装包内置 JSON 统一配置；你只要在设置页里手动改过一次，以后升级安装也**不会覆盖**你的选择（包括首页选项、播放器选项、DNS 等 25 项）。

**Q：首页图标/入口行和别的设备不一样？**
A：顶栏与快捷入口行允许被预置方案整体替换，属于正常定制；找不到「设置/组网」时，可在全部入口图标中查找，或向设备提供方确认预置配置。

**Q：下载的 App 安装不了？**
A：到「系统设置 → 安全/应用 → 安装未知应用」中允许 TVBox（或当前文件管理器）安装；返回 TVBox 首页会自动重新弹出安装。

**Q：组网连不上？**
A：见 [hin2n.md](file:///f:/tvbox-n2n/docs/hin2n.md) 的「常见问题」一节（版本一致、community/密钥一致、超节点可达、IP 不冲突、组播开关、日志排查）。

**Q：开机自启不生效？**
A：部分厂商系统有「自启动管理 / 后台弹出界面」白名单，需在系统管家中允许 TVBox 自启动；另外断电开机后网络/VPN 授权未就绪时可能首次不启动，重启一次即可。
